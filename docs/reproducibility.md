# 实验复现指南

## 1. 环境

需要 Python 3.11 或更高版本。建议在虚拟环境中安装：

```bash
python -m pip install -e '.[all,dev]'
python -m agentcomsim version
```

记录实际环境时保存 `python --version`、`pip freeze` 和操作系统信息。论文配置不依赖 GPU。

## 2. 快速验证

```bash
agentcomsim run -c configs/quickstart.yaml -o results/quickstart
pytest -q
```

快速配置用于检查安装，不应用于替代完整统计实验。

## 3. 完整参考实验

```bash
agentcomsim run -c configs/paper.yaml -o results/paper
```

实验矩阵为 3 个到达率 × 30 个独立种子 × 3 种策略，共 270 次运行。运行种子为 `base_seed + run_index`；同一到达率和种子下，各策略共享完整预生成轨迹。

输出包括：

- `config.resolved.yaml`：实际解析后的全部参数；
- `runs.csv`：每次独立运行的任务级汇总；
- `summary.csv` / `summary.json`：按到达率和策略聚合的均值与 95% 置信区间；
- `performance.png`：成功率和 P95 时延图；
- `events.jsonl`：仅在启用事件记录时生成。

## 4. 已核对的高负载结果

在当前发布代码、`configs/paper.yaml` 和到达率 1.6 个任务/秒下，完整运行得到：

| 策略 | 任务成功率均值 | P95 时延均值（秒） | 总传输量均值（MB） | 平均语义质量 |
|---|---:|---:|---:|---:|
| FIFO | 95.6377% | 1.482857 | 221.5825 | 1.000000 |
| 静态优先级 | 98.2672% | 1.254629 | 221.5825 | 1.000000 |
| TUS | 99.3072% | 1.167216 | 190.2933 | 0.986878 |

这些数值用于回归核对，而不是跨硬件的性能基准。仿真为离散事件计算，正常情况下不受 CPU 速度影响；依赖版本变化仍应通过完整配置和结果差异进行审查。

## 5. 统计口径

置信区间采用 `1.96 × 样本标准差 / sqrt(n)`，其中 `n` 是独立运行次数。它描述“运行均值的正态近似 95% 区间”，不是单次任务时延区间，也不是自动证明显著性的假设检验。独立运行较少或分布明显偏斜时，应增加运行次数并考虑 bootstrap 或适当统计检验。

## 6. 修改实验后的审查清单

1. 保存新的 YAML，不直接依赖代码内默认值。
2. 确认对照策略使用相同种子和到达率。
3. 区分预热期任务指标与全程字节统计。
4. 报告独立运行次数、均值、区间和尾时延计算方法。
5. 检查策略是否启用压缩；神经策略默认不压缩，不能只凭时延或成功率断言模型结构优劣。
6. 将输出目录与配置一并归档，并记录代码提交哈希。
